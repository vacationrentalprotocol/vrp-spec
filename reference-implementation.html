Reference Implementation

VRP is an open protocol. HemmaBo is, to our knowledge, the first commercial runtime; villaakerlyckan.se is HemmaBo's public proof node. It is not the only node: every known implementation, including the independent signing node, is listed with its evidence on the implementations page.

No central issuer. No registry gatekeeper. Any verifier can fetch discovery, JWKS, and a signed verified_stay_offer from the host-owned domain.

Proof path (copy-paste)

1. Host discovery https://villaakerlyckan.se/.well-known/vacation-rental.json 2. Node JWKS (Ed25519) https://villaakerlyckan.se/.well-known/jwks.json 3. Signed verified stay offer (fetch and verify it in your browser) https://villaakerlyckan.se/api/verified-stay-offer?check_in=…&check_out=…&guests=… 4. UCP profile (composes with VRP) https://villaakerlyckan.se/.well-known/ucp

HemmaBo (reference implementation)

  • www.hemmabo.com — operates the proof node
  • hemmabo-mcp-server — MCP server and verifier, Apache-2.0
  • The proof node declares operator.key_custody: platform: HemmaBo holds and operates its signing key on the host's behalf.

What the proof path shows

  • The offer was signed by a key the host domain publishes, has not been altered, and is within its stated lifetime (valid_until).
  • The signed offer carries the host domain's own statements of availability and exact price for the stay asked for.
  • The direct booking URL is on the host domain.
  • A valid signature proves the provenance and integrity of those statements; it does not guarantee that the stay is in fact available.

First-mover evidence

To our knowledge, Vacation Rental Protocol is the first open protocol focused on host-domain signed, AI-agent-readable vacation rental stay offers. See first-mover evidence memo.
